WEBEFY CALLER CRM - CODE PROTOTYPE

This is a browser-only working prototype using HTML/CSS/JavaScript and localStorage.

Included:
- Dashboard metrics
- Lead CRUD (add/edit)
- Lead statuses and follow-ups
- Search/filter
- Sales ledger
- Payment received tracking
- Commission calculation: 0-9 = 10%, 10-19 = 15%, 20+ = 20%
- Commission paid/pending view
- Caller/Admin mode toggle for UI testing
- Responsive layout

Run:
Open index.html in a browser, or serve the folder with any static web server.
